# Repository instructions

- Monorepo layout: `apps/web` (React SPA, pnpm), `services/*` (Python FastAPI services, uv), `libs/*` (shared Python packages), `skills/` (Agent Skills), `contracts/`, `apphost/` (Aspire TypeScript AppHost), `deploy/`. Use the pnpm workspace for TypeScript and the uv workspace (`uv sync`, `uv run`) for Python.
- Use `pnpm` for all package installation and package scripts. Do not use `npm` or `yarn`.
- Never bundle environment variables into the build. The SPA reads `/config.json` at runtime: `{ auth: { mode: "platform" | "oidc", authority, clientId, scope }, api: { backlog, agent }, agentId }`. Caddy serves it from container environment variables (`AUTH_MODE`, `OIDC_AUTHORITY`, `OIDC_CLIENT_ID`, `OIDC_SCOPE`, `AGENT_ID`) and proxies `/api/backlog` and `/api/agent`; the local Vite dev server serves it from `.env.local` and proxies the APIs (`BACKLOG_API_URL`, `AGENT_API_URL`). There is no browser-side LLM configuration; the browser never calls an LLM. Tokens are kept in `sessionStorage` only (never `localStorage`).
- Backlog templates are placeholder-free Markdown (no `{{…}}`); each item is one Markdown document. Default backlog templates live as Markdown files in `apps/web/src/defaults/templates/`. Persist user-customized full templates in IndexedDB and keep environment secrets out of configuration exports.
- Default agent principles and per-type instructions live as Markdown in `apps/web/src/defaults/instructions/`; user customizations are persisted in IndexedDB, are restorable, and are part of the configuration export.
- `docs/architecture.md` is the architecture/context document for humans and other agents. Read it before larger changes, and update it in the same change whenever structure, configuration, data formats, agent behaviour or features change (or new ones are added).
