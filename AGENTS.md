# Repository instructions

- Use `pnpm` for all package installation and package scripts. Do not use `npm` or `yarn`.
- Never bundle environment variables into the build. LLM defaults (`endpoint`, `model`, `streaming`) are read at runtime from `/config.json`; Caddy serves production values from container environment variables, and the local Vite dev server serves `/config.json` from `.env.local` (`LLM_ENDPOINT`, `LLM_MODEL`, `LLM_STREAMING`, `LOCAL_LLM_API_KEY`). The API key is only honoured in development. Users may enter endpoint, model and API key in the settings screen; these overrides are stored only in `localStorage` (`llm-connection-overrides`), win over config values, can be removed, and must never be part of the configuration export or application settings in IndexedDB. Models are listed via the OpenAI-compatible `GET /v1/models` (the configured endpoint is only the base URL; the app appends `/v1/chat/completions` and `/v1/models`); if that fails or returns nothing, the user types the model name manually.
- Backlog templates are placeholder-free Markdown (no `{{…}}`); each item is one Markdown document. Default backlog templates live as Markdown files in `src/defaults/templates/`. Persist user-customized full templates in IndexedDB and keep environment secrets out of configuration exports.
- Default agent principles and per-type instructions live as Markdown in `src/defaults/instructions/`; user customizations are persisted in IndexedDB, are restorable, and are part of the configuration export.
- `docs/architecture.md` is the architecture/context document for humans and other agents. Read it before larger changes, and update it in the same change whenever structure, configuration, data formats, agent behaviour or features change (or new ones are added).
