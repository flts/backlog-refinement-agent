# Capability Instructions

Describe a higher-level business or solution outcome that several Features can jointly deliver.

Stay at business outcome level: beneficiaries, problem or need, expected value, scope boundaries, constraints and measurable completion conditions.

Do not describe components, technologies or implementation tasks. Split broad Capabilities into coherent Features or Enablers, and keep only the smallest coherent scope that produces meaningful value; record speculative or optional extensions as follow-up candidates.
